FRESHMART SUPERMARKET FRONTEND

Files:
- index.html  -> page structure
- style.css   -> responsive design
- script.js   -> products, search, categories, cart, WhatsApp flow

RUN LOCALLY:
1. Open index.html directly in a browser, OR use VS Code Live Server.
2. In script.js, replace WHATSAPP_NUMBER with the store's WhatsApp number.
3. Replace the store name/address/phone text in index.html.
4. Replace emoji product visuals with real product images later.

WHATSAPP NOTE:
The order button opens the customer's WhatsApp app/site with a pre-filled message. The store receives the order in WhatsApp. There is no WhatsApp API backend in this V1.
